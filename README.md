# Tareq-Al-Mamun

Custom-built, ShoesVibe-inspired storefront built with vanilla HTML, CSS, and JavaScript. Browse curated sneakers, filter by category, search, and add products to a lightweight cart indicator with an animated toast.

## Running the site

1. From the project root, start a simple server (for example):
   ```bash
   python -m http.server 8000
   ```
2. Visit [http://localhost:8000](http://localhost:8000) in your browser to explore the experience.
