# Tareq-Al-Mamun

Custom-built, ShoesVibe-inspired storefront built with vanilla HTML, CSS, and JavaScript. Browse curated sneakers, filter by category, search, add products to a live cart, and complete a quick checkout within the built-in cart drawer.

## Running the site

1. From the project root, start a simple server (for example):
   ```bash
   python -m http.server 8000
   ```
2. Visit [http://localhost:8000](http://localhost:8000) in your browser to explore the experience.
3. Use the cart icon in the header to review your bag, adjust quantities, and submit the checkout form for a confirmation toast.
